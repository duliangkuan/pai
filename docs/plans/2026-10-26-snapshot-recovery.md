# 牌局存储恢复

生产 Neon 对 SELECT 也返回 402 quota exceeded，无法审计或清理云端数据。组织合计用量不代表本项目额度，不能据此判定是哪项超限。未删除任何既有云端存档。

采用本机优先保存：确认保存只写当前站点 localStorage，写入成功才提示成功；历史记录默认读本机，刷新、关闭后可重新加载。云端读取、同步由用户明确触发，避免重复唤醒数据库。跨设备可导出、导入 JSON 备份，导入合并且保留较新存档，不自动裁剪或淘汰存档。存储损坏、空间不足不能显示保存成功。

云端操作返回结构化成功/失败；读取失败不会伪装为空历史，删除失败保留本机条目。只返回用户可理解的错误，不向界面暴露数据库原始响应。移除每次请求的 CREATE TABLE；现有表保持原结构。云端历史每次读取 50 条，支持继续读取。

备选：仅清理数据无法解决计算时长额度；付费升级需要账户侧操作，且不能替代本地容错。当前范围先恢复教学工具和可靠存储。

验证：本机存储重读、满额/损坏保护、备份导入、同步去重、云端 402 与删除失败、分页边界；现有规则测试与生产构建；正式站保存、刷新、加载及云端失败的真实浏览器验收。
